# 设计理由与实现边界

本文重新整理早期《设计决策与权衡》和《可控熵注入设计概述》的解释。
下列取舍以当前源码为依据；旧版的性能估计、统计质量保证和状态表未作为验证结果保留。

## 为什么把统计计算放在主核

报文 worker 的主要工作是构造和提交报文，并将选中的样本交给每核采样环。
主核周期性调用熵统计计算，排序和计数不直接放进每个报文的构造路径。
这样使统计工作的复杂度不直接乘到每次构造上，也集中处理跨 worker 的统计窗口。

这不意味着观测没有成本。
采样选择、字段提取、环写入、缓存流量和主核读取都消耗资源；主核处理不及时还可能造成未读样本被覆盖。
当前 TX-only 路径在构造阶段暂存字段，仅为 PMD 接收的报文提交样本。
因此应结合采样间隔、覆盖计数和统计窗口看结果，而不是仅比较进程 CPU 百分比。

旧文“主核空闲超过 99%”“排序固定耗时 10–30 ms”“移到独立线程收益为零”不构成当前容量保证。
决定是否增加统计线程前，应先测量主核耗时、样本丢失和不同采样配置下的吞吐。
参考实现：`include/entropy.h`、`src/entropy_stats.c`、`src/worker.c`。
测量依据见[观测验证](../../reference/observability-validation-2026-08-03.md)与[profiling](../../guides/profiling.md)。

## 为什么使用每线程 PRNG

`src/define.c` 使用线程局部状态保存 xorshift64* 状态，避免 worker 竞争共享随机状态。
显式非零 seed 与 lcore ID 组合形成初始状态；自动模式结合 TSC 和线程标识，并防止状态为零。
实际返回值是乘法结果的 32 位截取，因此不能把某个算法变种的外部统计测试结论直接当作这条输出路径的验证。

不同调用返回不同位置的伪随机序列值，不等于数学上的独立随机变量。
范围取模、协议构造约束、重用同一个输出以及采样窗口都可能引入可见结构。
给每个维度新增状态也不能自动证明独立性，还会改变复现规则、初始化和调用成本。
如果 MI 异常，先固定配置和 seed，分离实际字段耦合与采样效应，再决定是否需要更换生成方法。
当前仓库没有为这条完整输出与范围映射路径提供 BigCrush/PractRand 验证记录。

固定 seed 的主要价值是复现伪随机选择。
它不固定调度、TSC、NIC 计数或所有异步采样边界；拓扑和构造调用顺序变化也会改变输出。
参见[确定性范围](../../guides/config.md#deterministic-scope)。

## 为什么先保留简单的比例误差调节

当前 `adapt_pps_rate()` 的行为是：

```text
新 PPS = clamp(当前 PPS + trunc((目标熵 - 实测熵) × gain), 0, 100000000)
```

每次统计更新产生增量，没有单独的积分误差累计器或微分项，但 PPS 本身会保留上次更新的结果。
发布采用一次 compare-exchange；若并发的显式 PPS 写入使比较失败，反馈更新放弃这次写入。

简单控制减少了微分项的噪声敏感性和积分饱和处理的复杂度。
这只是实现复杂度的取舍，不是稳定性证明。
低于目标时增加 PPS，不能翻译成“减速以提高随机性”；小于 1 的调整量会被截断；PPS 为零代表不限速，也不等于停止发送。
控制器观察的是本地生成流量的熵，不是 DUT 丢包反馈。
应先验证目标是否可达、统计证据是否充分，再测量 PPS 与熵的响应；没有通用的 gain 安全阈值。

## 为什么运行时只开放部分字段

批量、流量模型和部分 token bucket 参数在 worker 初始化时被复制或用于分配资源。
只修改共享配置中的同名数值，不会重新分配缓冲或重新建立这些状态。
当前描述表因此拒绝启动参数的运行时写入，而把可实时改变的数值发布到原子字段。

C11 原子访问解决单字段并发读写问题，不保证多字段事务。
先更新两个字段中的一个时，worker 可以观察到中间组合。
给普通字段外面套 generation counter 也不能消除数据竞争；若将来需要不可变快照，还必须解决旧快照的读者生命周期。
参见[并发参考](../../reference/concurrency.md)和[多字段更新设计](../../design/generation-boundary.md)。

## 交错、包长和显示平滑各自解决什么

交错对已构造批次的 mbuf 指针执行局部或完整洗牌，改变访问顺序，可用于比较连续流访问与混合流访问的缓存效应。
洗牌保持完整批次的字段直方图，不会凭空产生更多 IP 或连接，也不能保证每包都是缓存未命中。
同样的总熵可能对应不同的访问顺序，所以应同时观察时序、流键关系和 DUT 计数。

VXLAN 增加外层 Ethernet/IP/UDP/VXLAN 开销，内层大小约束和最终封装帧限制需要分别考虑。
不能把内层 MTU、`wire-mtu` 配置名、DPDK `pkt_len` 和包含 FCS/preamble/IFG 的链路线速字节混为一个量。
实际构造和封装见 `src/bless.c`，用[抓包与配置指南](../../guides/config.md#pcap-export)核对目标配置。

MI 对角线表示单变量熵，而非该变量与自身的独立性评分。
显示平滑改善读图连续性，会引入显示滞后，不能替代原始样本或用于证明耦合消失。
时延分位数也必须连同采样量和测量起止点读取；握手 SYN 到 SYN-ACK 的 RTT 与本地 TX 提交耗时不是同一种时延。
参见[仪表盘参考](../../guides/dashboard.md)与[握手实验](../../guides/handshake-experiment.md)。
